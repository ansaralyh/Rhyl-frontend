# How to Add Products with Images - Rhyl Super Store

## Quick Guide

### Step 1: Prepare Your Product Image
1. Save your product image in the `images` folder (e.g., `images/basmati-rice.jpg`)
2. Or use an external image URL (e.g., from a CDN or image hosting service)

### Step 2: Add Product in Admin Panel
1. Go to Admin Panel → Products
2. Click "+ Add Product"
3. Fill in the details:
   - **Product Title**: e.g., "Basmati Rice 5kg"
   - **Category**: Select from dropdown (e.g., "Grocery & Staples")
   - **Price**: e.g., 12.99
   - **Stock Quality**: e.g., 50
   - **Product Image URL**: Enter the path
     - For local images: `images/basmati-rice.jpg`
     - For external: `https://example.com/image.jpg`

### Step 3: Save and Verify
1. Click "Save Product"
2. Go to the main store page (index.html)
3. Scroll to the appropriate category section
4. Your product should now appear with the correct image!

## Tips
- Use descriptive filenames for images
- Keep image sizes reasonable (under 500KB recommended)
- Use JPG for photos, PNG for graphics with transparency
- Make sure the image path is correct (case-sensitive on some systems)
